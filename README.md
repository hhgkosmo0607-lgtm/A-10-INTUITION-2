# A-10-INTUITION(2)

팀 A-10-INTUITION(2)의 Track A 프로젝트입니다. 도구의 이름은 FactLock(팩트락)입니다.

타깃을 고르면 회사 자료에 있는 사실만으로 제품 묶음과 광고 글을 만들고, 내보내기 전에 자료와 다른 숫자·빠진 조건을 자동으로 검수하는 도구입니다.

제5회 AI 스마트워크톤 Track A에서 후원기업 티링크의 과제("홍보·리뷰 콘텐츠를 반복해서 만드는 일")를 풀기 위해 만듭니다.

## 지금 상태

브라우저에서 처음부터 끝까지 동작합니다. 2026-11-20에 확인했습니다.

- 타깃별 제품 묶음: 화면에 '제안, 담당자 확인 전'으로 표시됩니다.

## 왜 만드나

글쓰기를 AI에 그대로 맡기면 문장은 나오지만, 회사 자료와 맞는지는 사람이 따로 확인해야 합니다.
FactLock은 글을 쓰기 전에 사실 목록을 먼저 정하고, 그 안에서만 문구를 만들며, 규칙으로 검수합니다.

## 실행

uv(Python 환경·패키지 관리 도구)와 Python 3.12가 필요합니다. 저장소 최상위 폴더에서 실행합니다.

```bash
uv sync
```

```bash
uv run uvicorn factlock.web.main:app --port 8790
```

브라우저에서 `http://localhost:8790`을 엽니다. 타깃을 고르고 [다음]을 누르면 묶음과 견적, 초안, 검수 순서로 진행됩니다.

### AI로 초안을 새로 쓰게 하려면

`.env.example`을 `.env`로 복사해 Claude API 키를 넣고 아래처럼 실행합니다. `.env`는 Git에 올라가지 않습니다.

```bash
uv run --env-file .env uvicorn factlock.web.main:app --port 8790
```

- 키가 없거나 연결이 끊기면 미리 저장해 둔 초안을 불러오고, 화면에 그렇게 표시합니다.
- Claude API로는 사실 목록과 가이드라인만 보냅니다. 붙여 넣은 글은 보내지 않습니다.
- 검수와 견적 계산은 AI 없이 동작합니다.

`data/<회사>/` 폴더에 `facts.json`, `targets.json`, `guideline.json`, `drafts/`를 만들고 `FACTLOCK_DATA` 환경 변수로 그 폴더를 가리킵니다. 코드는 고치지 않습니다.
