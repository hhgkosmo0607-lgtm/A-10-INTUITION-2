# A-10-INTUITION(2)

팀 A-10-INTUITION(2)의 Track A 프로젝트입니다. 도구의 이름은 FactLock(팩트락)입니다.

타깃을 고르면 회사 자료에 있는 사실만으로 제품 묶음과 광고 글을 만들고, 내보내기 전에 자료와 다른 숫자·빠진 조건을 자동으로 검수하는 도구입니다.

제5회 AI 스마트워크톤 Track A에서 후원기업 티링크의 과제("홍보·리뷰 콘텐츠를 반복해서 만드는 일")를 풀기 위해 만듭니다.

## 지금 상태

브라우저에서 처음부터 끝까지 동작합니다. 2026-11-20에 확인했습니다.

| 단계 | AI가 하는 일 | 규칙이 하는 일 | 확인한 방법 |
|---|---|---|---|
| 타깃과 묶음 | 고객 설명을 읽고 사실 목록에서 제품·고민·가격·조건을 고름 | 목록에 없는 번호와 '확인 필요' 사실을 버림 | Codex 구독으로 실제 실행 (약 16초) |
| 예시 견적 | 없음 | 가격 사실로 계산하고 조건을 붙임 | 테스트 |
| 초안 | 사실 목록 안에서 글을 쓰고 문장마다 근거 번호를 붙임 | 근거와 맞지 않는 문장을 뺌(사실 잠금) | Codex 구독으로 실제 실행 (약 1분, 문장 27~44개, 빠진 문장 0개) |
| 검수 | 숫자 없이 뜻이 틀린 문장을 찾음 | 규칙 10개로 통과·실패 판정 | Codex 구독으로 실제 실행 (약 15초) |

- 준비된 타깃은 6개입니다: 외근 영업 조직, 재택 콜센터, 학교, 소호 사무실, 전화 영업·보험대리점, 다국어 현장. 목록에 없는 고객은 글로 적으면 AI가 묶음을 만듭니다.
- 사실 목록은 86개입니다(확인 필요 1개, 회사 주장 1개 포함).
- AI가 찾은 문제는 '실패'가 아니라 '확인 필요'로 표시합니다. 통과·실패는 규칙만 정합니다.
- 저장된 초안은 '외근 영업 조직'과 '재택 콜센터' 두 개뿐입니다. 나머지 타깃은 AI가 연결되어야 초안이 나옵니다.

아직 확인하지 못한 것
- Claude Code CLI와 Claude API 경로: 코드는 있지만 이 컴퓨터의 Claude Code 로그인이 만료되어 실제로 실행하지 못했습니다.
- 강조 항목 11개를 알아보는 낱말과 타깃별 묶음: 담당자 확인 전이라 화면에 '확인 필요', '제안'으로 표시됩니다.

## 왜 만드나

글쓰기를 AI에 그대로 맡기면 문장은 나오지만, 회사 자료와 맞는지는 사람이 따로 확인해야 합니다.
FactLock은 글을 쓰기 전에 사실 목록을 먼저 정하고, 그 안에서만 문구를 만들며, 규칙으로 검수합니다.

## 실행

uv(Python 환경·패키지 관리 도구)와 Python 3.12가 필요합니다. 저장소 최상위 폴더에서 실행합니다.

```bash
uv sync
```

```bash
uv run uvicorn factlock.web.main:app --port 8790
```

브라우저에서 `http://localhost:8790`을 엽니다. 타깃을 고르고 [다음]을 누르면 묶음과 견적, 초안, 검수 순서로 진행됩니다.

### AI 연결

AI는 세 가지 방법 중 되는 것을 순서대로 씁니다. 화면 위쪽에 연결된 방법이 표시됩니다.

| 순서 | 방법 | 필요한 것 |
|---|---|---|
| 1 | Claude API | `.env`에 `ANTHROPIC_API_KEY` (`.env.example` 참고) |
| 2 | Claude Code CLI (Claude 구독) | 터미널에서 `claude`를 실행해 로그인 |
| 3 | Codex CLI (ChatGPT 구독) | 터미널에서 `codex`를 실행해 로그인 |

- `FACTLOCK_AI` 환경 변수로 하나만 고를 수 있습니다: `auto`(기본), `api`, `claude-cli`, `codex-cli`, `off`.
- CLI는 빈 임시 폴더에서 도구 없이 실행합니다. 프로젝트 파일을 읽거나 바꾸지 못합니다.
- AI로는 사실 목록과 가이드라인, 검수할 때는 검수할 글을 보냅니다. '확인 필요' 사실은 보내지 않습니다.
- AI가 답하지 못하면 저장된 초안을 불러오고 화면에 그렇게 표시합니다. 규칙 검수와 견적은 AI 없이 동작합니다.

`data/<회사>/` 폴더에 `facts.json`, `targets.json`, `guideline.json`, `drafts/`를 만들고 `FACTLOCK_DATA` 환경 변수로 그 폴더를 가리킵니다. 코드는 고치지 않습니다.
