# A-10-INTUITION(2)

팀 A-10-INTUITION(2)의 Track A 프로젝트입니다. 도구의 이름은 FactLock(팩트락)입니다.

타깃을 고르면 회사 자료에 있는 사실만으로 제품 묶음과 광고 글을 만들고, 내보내기 전에 자료와 다른 숫자·빠진 조건을 자동으로 검수하는 도구입니다.

제5회 AI 스마트워크톤 Track A에서 후원기업 티링크의 과제("홍보·리뷰 콘텐츠를 반복해서 만드는 일")를 풀기 위해 만듭니다.

## 지금 상태

브라우저에서 처음부터 끝까지 동작합니다. 2026-11-20에 확인했습니다.

### 결과물은 두 가지입니다

| 결과물 | 내용 | 내보내기 |
|---|---|---|
| 블로그 글 | 네이버·티스토리에 붙여 넣는 글 한 편. 소제목 아래에 홍보 이미지를 골라 넣을 수 있음 | 글 복사, 서식 포함 복사, `.md` 내려받기 |
| 인스타 캐러셀 | 넘겨 보는 카드(3~10장), 게시물 문구, 해시태그(5개 이내). 카드 배경에 홍보 이미지를 넣을 수 있음 | 카드 PNG 내려받기, 문구 복사 |

### 화면 순서

1. **타깃 고르기**: 준비된 타깃 6개 중에서 고르거나, 고객을 글로 적어 타깃을 추가합니다.
2. **넣을 내용 정하기**: 사실 목록에서 자동으로 골라진 고민·제품·조건을 확인합니다. 꼭 넣을 내용을 고르거나 직접 추가하고, 가격을 넣을지 정합니다.
3. **결과물**: 블로그 글과 인스타 캐러셀이 함께 만들어지고, 탭으로 나란히 봅니다. 고친 뒤 검수를 통과해야 내보낼 수 있습니다.

그 밖에 받은 글 검수, 사실 목록, 자료 저장소가 있습니다. 자료 저장소에는 사내 문서(원본을 보관하고 AI가 사실을 뽑음)와 홍보 이미지를 넣습니다.

### AI가 하는 일과 규칙이 하는 일

| 단계 | AI가 하는 일 | 규칙이 하는 일 | 확인한 방법 |
|---|---|---|---|
| 타깃 추가 | 고객 설명을 읽고 사실 목록에서 제품·고민·가격·조건을 고름 | 목록에 없는 번호와 '확인 필요' 사실을 버림 | Codex 구독으로 실제 실행 (약 16초) |
| 블로그 글 | 사실 목록 안에서 글을 쓰고 문장마다 근거 번호를 붙임 | 근거와 맞지 않는 문장을 뺌(사실 잠금) | Codex 구독으로 실제 실행 (약 1~2분, 빠진 문장 0개) |
| 인스타 캐러셀 | 카드·문구·해시태그를 쓰고 근거 번호를 붙임 | 근거와 맞지 않는 카드·문장·해시태그를 뺌 | Codex 구독으로 실제 실행 (카드 7장, 빠진 것 0개) |
| 사내 문서에서 사실 읽기 | 문서(PDF, PPTX, DOCX, XLSX, TXT)에서 사실을 뽑고 원문을 인용함 | 인용이 문서에 없거나 숫자가 원문과 다르면 버림. 남은 것은 '확정 대기' | Codex 구독으로 제안서(슬라이드 11장)에서 사실 15개 추출 (약 40초) |
| 검수 | 숫자 없이 뜻이 틀린 문장을 찾음('확인 필요'로만 표시) | 통과·실패 판정 | Codex 구독으로 실제 실행 (약 15초) |
| 예시 견적 | 없음 | 가격 사실로 계산하고 조건을 붙임 | 테스트 |

- 가격은 기본으로 넣지 않습니다. '글에 가격 넣기'를 고르면 가격과 그 조건(부가세 별도, 예시 견적 등)이 함께 들어갑니다.
- 담당자가 직접 추가한 내용은 출처가 '담당자가 직접 입력'으로 사실 목록에 기록됩니다.
- 사실 목록은 86개에서 시작합니다(확인 필요 1개, 회사 주장 1개 포함). 온라인 출처는 그 페이지로 가는 링크가, 문서에서 읽은 사실은 파일 이름·쪽 번호·원문 인용이 붙습니다.
- 사내 문서 원본, 문서에서 읽은 사실, 직접 추가한 사실, 홍보 이미지는 `var/`에 저장되고 Git에 올라가지 않습니다.
- 문서에서 읽은 사실은 원본 문서로 가는 링크와 쪽 번호, 원문 인용을 함께 가집니다. 문서를 지우면 그 문서에서 읽은 사실도 함께 지워집니다.
- 저장된 초안은 '외근 영업 조직'(블로그 글, 캐러셀)과 '재택 콜센터'(블로그 글)뿐입니다. 나머지는 AI가 연결되어야 만들어집니다.

아직 확인하지 못한 것
- Claude Code CLI와 Claude API 경로: 코드는 있지만 이 컴퓨터의 Claude Code 로그인이 만료되어 실행하지 못했습니다.
- '꼭 넣을 내용'을 AI가 실제로 반영하는지: 가짜 AI와 저장된 초안으로만 확인했습니다. 반영되지 않으면 검수표가 실패로 알립니다.
- 강조 항목 11개를 알아보는 낱말과 타깃별 내용: 담당자 확인 전이라 화면에 '확인 필요', '제안'으로 표시됩니다.
- 추가한 타깃은 서버를 다시 켜면 사라집니다.

## 왜 만드나

글쓰기를 AI에 그대로 맡기면 문장은 나오지만, 회사 자료와 맞는지는 사람이 따로 확인해야 합니다.
FactLock은 글을 쓰기 전에 사실 목록을 먼저 정하고, 그 안에서만 문구를 만들며, 규칙으로 검수합니다.

## 실행

uv(Python 환경·패키지 관리 도구)와 Python 3.12가 필요합니다. 저장소 최상위 폴더에서 실행합니다.

```bash
uv sync
```

```bash
uv run uvicorn factlock.web.main:app --port 8790
```

브라우저에서 `http://localhost:8790`을 엽니다. 타깃을 고르고 [다음]을 누르면 묶음과 견적, 초안, 검수 순서로 진행됩니다.

### AI 연결

AI는 세 가지 방법 중 되는 것을 순서대로 씁니다. 화면 위쪽에 연결된 방법이 표시됩니다.

| 순서 | 방법 | 필요한 것 |
|---|---|---|
| 1 | Claude API | `.env`에 `ANTHROPIC_API_KEY` (`.env.example` 참고) |
| 2 | Claude Code CLI (Claude 구독) | 터미널에서 `claude`를 실행해 로그인 |
| 3 | Codex CLI (ChatGPT 구독) | 터미널에서 `codex`를 실행해 로그인 |

- `FACTLOCK_AI` 환경 변수로 하나만 고를 수 있습니다: `auto`(기본), `api`, `claude-cli`, `codex-cli`, `off`.
- CLI는 빈 임시 폴더에서 도구 없이 실행합니다. 프로젝트 파일을 읽거나 바꾸지 못합니다.
- AI로는 사실 목록과 가이드라인, 검수할 때는 검수할 글을 보냅니다. '확인 필요' 사실은 보내지 않습니다.
- AI가 답하지 못하면 저장된 초안을 불러오고 화면에 그렇게 표시합니다. 규칙 검수와 견적은 AI 없이 동작합니다.
