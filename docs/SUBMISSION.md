## ② 1단계 기획서

[프로젝트명]
애드체크

[한 줄 소개]
회사 자료에 있는 사실만으로 블로그 글과 인스타 게시글을 만들고, 내보내기 전에 자료와 다른 숫자·빠진 조건을 검수하는 도구

[대상 사용자]
제품이 여러 개인데 전담 마케터가 없는 소규모 B2B 기업의 홍보 담당자. 첫 사용자는 상주 인원 7명으로 홈페이지 메뉴 기준 9가지 통신·녹취 서비스를 파는 티링크의 담당자입니다. 블로그 글과 리뷰 가이드라인을 관리하는 사람입니다.

[해결하려는 문제]
티링크의 자료, 홈페이지 20개 페이지, 공식 블로그 글 38개를 모두 읽고 확인한 문제입니다.

1. 제품이 9가지라 글마다 무엇을 누구에게 말하는지 흩어집니다. 가이드라인의 제품명 '티링크 비즈레코딩'은 홈페이지의 보이는 글에는 없고, 이미지 설명에만 두 번 나옵니다.
2. 글마다 숫자가 다릅니다. 고객관리 서비스의 초기 비용이 블로그 글에는 '설치비 20만 원', 홈페이지 견적에는 '설정비 30만 원'으로 적혀 있어 읽는 사람은 어느 쪽이 맞는지 알 수 없습니다. 학교 실적도 페이지에 따라 '150여 개'와 '200여 개'로 다릅니다.
3. 검수 없이 게시됩니다. 2026년 10월 블로그 글 1개에 "[이미지 삽입: ...]"이라는 작업 메모가 3군데 남아 있습니다.
4. 리뷰 가이드라인은 필수 키워드 3개와 강조 내용 11가지를 요구하는데, 받은 글이 이를 지켰는지는 사람이 눈으로 대조해야 합니다.
5. 꾸준히 만들기 어렵습니다. 블로그는 2025년 1월 이후 약 20개월 동안 새 글이 없다가 2026년 9~11월에 10개가 올라왔습니다.

글쓰기를 AI에 그대로 맡기면 문장은 나오지만, 회사 자료와 맞는지는 사람이 따로 확인해야 합니다. 검수에 드는 시간은 아직 재지 못했습니다. 담당자에게 확인이 필요합니다.

[해결 방법]
AI는 네 곳에 쓰고, AI의 답은 항상 사실 목록과 대조한 뒤에만 씁니다. 통과·실패는 AI가 아니라 규칙이 정합니다.

1. 자료 읽기(AI): 사내 문서(PDF, PPTX, DOCX, XLSX, TXT)를 넣으면 AI가 사실을 뽑고 원문을 인용합니다. 인용이 문서에 실제로 없거나 숫자가 원문과 다르면 버립니다. 남은 사실은 담당자가 확정해야 쓸 수 있습니다.
2. 타깃과 내용 구성(AI + 사람): 타깃을 고르면 사실 목록에서 고객 과제, 제안 제품, 필수 고지 사항이 기본값으로 채워집니다. 목록에 없는 고객은 글로 적으면 AI가 새 타깃을 만듭니다. 담당자는 체크로 넣을 항목을 고르고, 앞세울 항목을 강조로 표시합니다.
3. 글 만들기(AI + 규칙): AI가 사실 목록 안에서만 블로그 글과 인스타 게시글을 쓰고 문장마다 근거 사실 번호를 붙입니다. 서버가 문장 속 숫자·가격·제품명을 그 사실과 대조해, 맞지 않는 문장은 빼고 이유를 보여 줍니다. 체험 후기는 AI가 지어내지 않고 사람이 채울 빈칸으로 둡니다.
4. 검수(규칙 + AI): 필수 키워드, 강조 항목, 하단 문의 정보, 자료와 다른 숫자, 빠진 고지 사항, 남은 작업 메모, 근거 없는 최상급 표현을 규칙으로 검사합니다. AI는 숫자 없이 뜻이 틀린 문장을 찾아 '확인 필요'로만 알립니다. 체험단이 써 온 글도 같은 기준으로 검사합니다.

실제 게시와 발송은 사람이 합니다.

[주요 기능]
핵심 기능 3개
1. 사실 목록과 타깃별 내용 구성: 가격·숫자·조건을 출처(페이지 링크 또는 문서 원문 인용)와 함께 보여 주고, 타깃에 맞는 고객 과제·제안 제품·필수 고지 사항을 체크로 고름
2. 사실 기반 결과물 생성: 블로그 글(네이버·티스토리용)과 인스타 게시글(카드, 게시물 문구, 해시태그 5개 이내)을 문장마다 근거 번호를 붙여 생성
3. 자동 검수: 만든 글과 받은 글을 같은 기준으로 검사하고, 실패가 있으면 내보내기를 막음

MVP 범위: 티링크 한 회사, 준비된 타깃 6개와 직접 추가, 결과물은 블로그 글과 인스타 게시글 두 가지

제외한 기능: 블로그·SNS 자동 게시, 문자 자동 발송, 영상 제작, 광고 관련 법률 판단(담당자 확인 항목으로만 표시), 한글(HWP) 문서와 스캔본 읽기

[기술 스택]
AI 모델: Codex CLI(ChatGPT 구독)로 실행을 확인했습니다. Claude Code CLI와 Claude API도 연결할 수 있게 만들었지만 실행으로 확인하지는 못했습니다. 개발에는 Claude Code를 썼습니다.
백엔드: Python 3.12, FastAPI, SQLite, 문서 읽기(pypdf, openpyxl)
검수 엔진: 순수 Python 규칙(사실 잠금, 키워드·조건 검사, 견적 계산), pytest 143건으로 검증
화면: HTML·JavaScript(카드 이미지는 브라우저에서 그림)
공개: GitHub
