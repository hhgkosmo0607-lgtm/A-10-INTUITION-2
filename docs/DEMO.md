# 시연 영상 대본

2단계 제출용 시연 영상을 찍을 때 보는 문서입니다. 3분 안팎을 기준으로 했습니다.
영상은 유튜브에 "공개"로 올린 가로 영상이어야 하고, 숏츠는 안 됩니다.

## 찍기 전에

1. 서버를 켭니다.

   ```bash
   uv run uvicorn factlock.web.main:app --port 8790
   ```

2. 브라우저에서 `http://localhost:8790`을 열고 창을 넓게 둡니다. 왼쪽에 메뉴가 보여야 합니다.
3. 화면 왼쪽 아래에 "AI 연결됨"이 보이는지 확인합니다. 안 보이면 터미널에서 `codex`를 실행해 로그인합니다.
4. AI 생성은 1~2분 걸립니다. 영상에서는 기다리는 부분을 잘라 내거나, 미리 한 번 생성해 둔 화면에서 이어 찍습니다.
5. 화면에 개인 정보(북마크, 다른 탭, 알림)가 보이지 않게 합니다.
6. 아래 "틀린 글"을 메모장에 복사해 둡니다.

## 순서

| 시간 | 화면 | 할 말 |
|---|---|---|
| 0:00~0:20 | 티링크 블로그의 실제 글(작업 메모가 남은 부분) | "티링크는 9가지 서비스를 7명이 운영합니다. 홍보 글을 직접 쓰는데, 올린 글에 '이미지 삽입'이라는 작업 메모가 그대로 남아 있고 설치비가 홈페이지와 다르게 적혀 있습니다." |
| 0:20~0:35 | 애드체크 첫 화면, 사실 목록 | "애드체크는 글을 쓰기 전에 사실 목록부터 정합니다. 모든 사실에 출처가 붙어 있고, 자료끼리 값이 다르면 '근거 부족'으로 잠급니다." |
| 0:35~1:00 | 1 타깃 선택 → 2 내용 구성 | "타깃을 고르면 고객 과제, 제안 제품, 필수 고지 사항이 사실 목록에서 채워집니다. 체크한 것만 글에 들어가고, 앞세울 항목은 강조로 표시합니다." (강조 버튼을 눌러 파란 테두리를 보여 줌) |
| 1:00~1:40 | [둘 다 생성] → 3 결과물, 블로그 글 | "AI가 사실 목록 안에서만 글을 씁니다. 문장 끝의 번호를 누르면 근거와 출처가 바로 아래에 나옵니다. 체험 후기는 AI가 지어내지 않고 빈칸으로 둡니다." (번호를 눌러 근거 상자를 보여 줌) |
| 1:40~2:05 | 인스타 게시글 탭 | "같은 내용으로 인스타 카드와 문구, 해시태그도 함께 나옵니다. 카드 그림은 내려받을 수 있습니다." |
| 2:05~2:40 | 2 내용 구성 → 체험단 글 검수 [추가] → 틀린 글 붙여 넣기 → [검수] | "체험단이 써 온 글도 같은 기준으로 검사합니다. 설치비가 자료와 다르고, 작업 메모가 남았고, 부가세 조건이 빠졌다고 알려 줍니다." |
| 2:40~3:00 | 자료 저장소 | "사내 문서를 넣으면 AI가 사실을 뽑고 원문을 인용합니다. 인용이 문서에 없으면 버리고, 담당자가 확정해야 쓸 수 있습니다. 실제 게시는 사람이 합니다." |

## 틀린 글 (체험단 글 검수에 붙여 넣을 합성 글)

제목

```text
고객관리 프로그램 사용 후기
```

본문

```text
안녕하세요. 오늘은 고객관리 프로그램을 소개합니다.
전화가 오면 고객 정보가 바로 뜨고 상담 이력을 한 화면에서 관리합니다.
A타입은 상담원당 월 30,000원이고 설치비는 20만 원입니다.
[이미지 삽입: 고객 조회 화면]
전국 학교 200여 곳이 사용하는 업계 최고 솔루션입니다.
상담 문의: 1877-3836
```

이 글을 넣으면 다음이 실패로 나옵니다.
- 자료와 다른 값: 설치비 20만 원(자료는 300,000원)
- 근거 부족 값: 학교 200여 곳
- 필수 조건: 부가세 별도, 예시 견적, 최소 3명
- 남은 작업 메모: 1건
- 최상급·비교: 업계 최고

## 질문을 받으면

| 질문 | 답 |
|---|---|
| AI는 어디에 썼나요? | 자료에서 사실 뽑기, 타깃 추가, 글 쓰기, 뜻이 틀린 문장 찾기에 썼습니다. 통과와 실패는 AI가 아니라 규칙이 정합니다. |
| AI가 틀린 말을 쓰면요? | 문장마다 근거 번호를 붙이게 하고, 숫자와 제품명이 근거와 다르면 그 문장을 뺍니다. 뺀 문장은 이유와 함께 보여 줍니다. |
| 효과가 얼마나 되나요? | 아직 재지 못했습니다. 담당자가 실제로 써 본 적이 없습니다. 확인한 것은 실제 블로그 글 1편에서 작업 메모 3건과 다른 설치비 1건을 찾았다는 것입니다. |
| 다른 회사도 쓸 수 있나요? | 회사마다 데이터 폴더 하나를 두는 구조입니다. 다만 다른 회사로 실제로 해 보지는 않았습니다. |
| 그림은 실제 화면인가요? | 아닙니다. 홍보 이미지가 없을 때 넣는 예시 그림이고 그림마다 표시가 있습니다. 실제 이미지를 자료 저장소에 넣으면 그 이미지가 쓰입니다. |
