      꼭 넣을 내용 (선택)

      위 묶음은 사실 목록에서 자동으로 골라진 것입니다. 글에 꼭 넣고 싶은 내용이 있으면 사실 목록에서 고르거나 직접 적어 추가하세요.

      직접 추가한 내용은 출처가 '담당자가 직접 입력'으로 사실 목록에 기록되고, 담당자가 책임지는 사실로 취급됩니다.

      가격 (선택)

      광고 글에는 보통 가격을 넣지 않습니다. 넣으면 부가세 별도·예시 견적 같은 조건이 함께 들어갑니다.

      글에 들어갈 가격의 근거입니다. 상담원 수를 바꾸면 예시 견적을 다시 계산합니다.

      체험단 글 검수 · 받은 글이 위 내용과 맞는지 확인

      체험단이 써 온 글이나 이미 올린 글을 붙여 넣으면, 이 타깃의 내용·조건과 가이드라인을 기준으로 검사합니다.

      결과물 생성

      블로그 글(네이버·티스토리용) 한 편과 인스타 캐러셀(넘겨 보는 카드, 게시물 문구, 해시태그 5개 이내)을 함께 만듭니다.

      인스타 캐러셀

      글을 고치면 카드 그림이 바로 바뀝니다. 고친 뒤에는 [재검수]를 눌러 주세요.

      해시태그

      사실 잠금에서 빠진 것

      블로그 글 초안

      문장 끝의 번호를 누르면 근거가 된 사실과 출처가 보입니다.

      사실 잠금에서 빠진 문장

      AI가 쓴 문장 가운데 근거 사실과 맞지 않아 뺀 문장입니다.

      문장뺀 이유

      검수와 내보내기

      글을 고친 뒤 [재검수]를 누르세요. 실패가 없어야 내려받을 수 있습니다.

      완성본 미리보기

      블로그에 올렸을 때의 모습입니다. 실제 게시는 하지 않습니다.

      소제목 아래에 넣을 이미지

      자료 저장소의 이미지를 고르면 미리보기에 들어갑니다. 블로그에는 이미지를 직접 올려야 하며, 내려받은 글에는 넣을 위치와 파일 이름이 표시됩니다.

      '예시 그림'은 실제 화면이 아니라 설명용 그림입니다. 실제 화면처럼 소개하지 마세요.

      사실 목록

      광고 문구는 이 목록의 '확정' 사실로만 씁니다. '확인 필요'는 자료끼리 값이 달라 쓸 수 없습니다.

      사내 문서에서 사실을 읽으려면 [자료 저장소]에 문서를 넣어 주세요. 읽은 사실은 여기에 '확정 대기'로 나타납니다.

      전체 사실

      번호사실상태출처

      자료 저장소

      사내 문서와 홍보 이미지를 넣어 두는 곳입니다. 이 컴퓨터에만 저장되고 Git에는 올라가지 않습니다.

      사내 문서

      제안서, 매뉴얼, 소개서 같은 문서를 넣으면 원본을 보관하고 AI가 광고에 쓸 사실을 뽑습니다. 문서에 실제로 있는 문장을 인용한 것만 남고, [사실 목록]에서 확정해야 글에 쓰입니다.

      PDF, PPTX, DOCX, XLSX, TXT · 30MB 이하. 분석에 1~2분 걸립니다.

      문서쪽수뽑은 사실넣은 날

      가이드라인

      글이 지켜야 할 규칙(필수 키워드, 강조 항목, 하단 정보)을 적은 엑셀입니다. 사실을 뽑는 사내 문서와는 쓰임이 다릅니다. 올리지 않으면 저장된 티링크 가이드라인을 씁니다.

      홍보 이미지

      실제 서비스 화면, 제품 사진입니다. 인스타 카드의 배경과 블로그 글의 소제목 아래에 골라 넣습니다.

      PNG, JPG, WEBP · 10MB 이하. 사용 권한이 있는 이미지만 넣어 주세요. 고객 정보가 보이는 화면은 가린 뒤에 넣어 주세요.
